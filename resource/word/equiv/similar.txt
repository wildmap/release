# 形近字等价表：字形相似、被用来做替换绕过的字
#
# 一行一组，组内字符互为等价；**第一个字符是规范形**，匹配前其余字符一律折叠为它。
# 折叠对词库和玩家输入同时生效，因此一个 3 字词、每个字 5 种写法，等于凭空覆盖
# 了 125 种变体，而内存不变——这就是"变种词库"的实现方式。
#
# 收词原则：只收**确实被用于绕过**的字。把常用字折叠到一起会让正常句子被误判，
# 而误判在聊天里表现为"我没说脏话却被打了星号"，比漏判更容易被玩家察觉。
#
